A small project for the weekend

18 may 2026
Your name

This weekend’s project is deliberately small: make a notebook for the things I want to try. One page per idea, with room for a sketch and the next step.

Three things to start with

  1. A place to collect ideas before they get lost.
  2. A short list of materials I already have.
  3. One action I can finish in an afternoon.

The notebook does not need to be beautiful. It needs to be easy to open.

A few useful places

  • The Public Domain Review for unexpected stories and visual inspiration.
  • Project Gutenberg for books to browse and return to.
  • Chulapa for the theme behind this journal.

The next step

I will choose one idea and write down what happened, including the parts that did not work. A small finished experiment teaches me more than a perfect plan.
